# 大数据招聘岗位数据分析

> 用 4,002 条公开招聘数据回答一个具体问题：**以专科应届生的条件，数据分析类岗位的真实机会在哪里、门槛落在学历还是经验上、起薪的合理区间是多少。**

一个从原始脏表格出发、到可执行求职策略结束的完整数据分析项目。全程独立完成：数据可信度核查、清洗规则设计、口径控制、EDA、可视化与结论提炼。

**在线浏览**：[可视化总览](https://zhanqing9029.github.io/job-market-analysis/) · [完整报告（网页版）](https://zhanqing9029.github.io/job-market-analysis/report.html) · [报告 Markdown](REPORT.md) · [清洗与 EDA 笔记本](src/%E6%95%B0%E6%8D%AE%E6%B8%85%E6%B4%97%E4%B8%8EEDA.ipynb)

## 四条结论（都可以直接变成投递动作）

| # | 结论 | 关键数据 | 动作 |
|---|---|---|---|
| 1 | 「数据统计」不是数据分析的平替 | 数据分析 2,990 条中位 ¥18,500；数据统计 75 条中位 ¥9,000，**低 51%** | 简历标题统一写「数据分析」，排除含「统计员/数据专员」的岗位 |
| 2 | 学历不占优时，广州深圳的机会密度高于北京 | TOP5 城市占 63.5%；但「大专 + 应届可投」的 169 条中，**广州 36 > 上海 30 > 北京 14** | 优先在广州、深圳投递，北京留到有 1-3 年经验后再试 |
| 3 | 不要海投「本科起」，把条件锁死在 169 条上 | 本科岗占 78.4%，但**大专岗 43.7% 对无经验开放，本科岗只有 20.4%** | 筛选条件固定为「大专 + 经验不限/1 年以内」，在这 169 条上做深度定制 |
| 4 | 第一份工作先拿「1-3 年」标签，别纠结起薪 | 1 年以内 ¥10,000 → 1-3 年 ¥18,000（**+80%**）→ 3-5 年 ¥30,000（+67%） | 优先投明确写「1 年以内」的岗位；「经验不限」的岗位中位仅 ¥9,000，是低薪信号而非好进门 |

## 这个项目里最值得看的三处判断

图表谁都能画，真正区分水平的是「在什么地方做了判断、为什么这么判断」。

### 一、缺失值不填充：先判断缺失机制，再决定处理方式

城市字段缺失 600 条（15.0%）。常规做法是填众数或直接删除，但这两种都会让结论出错：

| 分组 | 条数 | 月薪中位数 |
|---|---|---|
| 城市缺失 | 487 | **¥27,500** |
| 北京 | 516 | ¥22,500 |
| 上海 | 766 | ¥20,000 |

缺失组的薪资比任何一个真实城市都高。合理的解释是**高薪岗位（猎头代招、保密招聘）更倾向不公开城市**，缺失机制是 MNAR 而非 MCAR。填均值会把这批高薪岗拉到平均水平，直接删除则会让整体薪资被系统性低估。

**处理**：标记为「未知」作为独立类别保留，城市对比时单独排除，并把这个现象本身作为一条发现写进报告。

### 二、异常值标记但不删除

月薪分布偏度 2.18、峰度 10.0，是典型的右偏长尾。IQR 判定的 68 行（2.0%）统计异常值如果直接删除，等于人为削掉右尾，而右尾恰恰是「高薪岗位长什么样」的信息所在。

**处理**：分三类判定——统计异常（标记保留）、业务异常（月薪 < 1,000、几薪 > 24，剔除出薪资统计）、逻辑异常（薪资倒挂、公司名等于行业词、城市填省份，打标）。

### 三、三层口径控制：结论会变，但不会消失

单看分组结果会说「大专 ¥9,000、本科 ¥20,000，差 55%」，但这是混合口径，把学历差异和岗位结构差异混在了一起。

| 口径 | 大专 | 本科 | 差距 |
|---|---|---|---|
| 全量 | ¥9,000 (n=366) | ¥20,000 (n=2,601) | −55.0% |
| 固定岗位方向 | ¥9,000 (n=327) | ¥20,000 (n=2,348) | −55.0% |
| 固定方向 + 固定职级 | ¥10,000 (n=198) | ¥17,500 (n=1,438) | **−42.9%** |

收窄 12.1 个百分点，占总差距的 22%。结论只能写「结构效应解释一小部分，学历门槛真实存在」，不能写「差距全是结构造成的」。这类「控制变量后缩水但仍显著」的表述，比任何一边倒的说法都更经得起追问。

## 局限（主动说明）

1. **数据年份偏旧**（2019-12）。薪资绝对值不代表当前行情，本项目所有结论限定在「结构」与「相对差异」层面，未把任何绝对薪资当作当下预期。
2. **抓取关键词单一**（仅「数据分析」）。因此「数据开发/数仓」只有 6 条、「BI/报表」69 条，这是采样偏差，不代表市场真实占比。
3. **缺少 JD 全文**。无法做技能维度分析（SQL / Python / Hive / Tableau 的提及率、技能组合溢价），这是本项目最大的能力缺口。
4. **薪资是 JD 挂牌区间的中点**，不等于实际 offer；645 条「面议」岗位被整体排除，可能引入样本选择偏差。

后续优化方向见 [REPORT.md 6.3](REPORT.md#6-项目总结局限性与后续优化)。
